# Tek Kalan Çorabın Lahey Davası

> Bu belge Birleşmiş Milletler Çamaşır Hukuku Komisyonu'nun 1923'ten beri bekleyen taslağıdır.
> Bilimsel dayanak: yok. Duygusal dayanak: çok.

## Ne yapar?

Makineden çıkan çiftin birini kaybeden vatandaş adına, **tek kalan çorap** kayıp eşini Lahey Uluslararası Adalet Divanı'nda dava eder.

Program:
1. Çorabın rengini, bedenini ve duygusal bağını kaydeder.
2. Kayıp eş için uluslararası yakalama emri çıkarır (emir, evin içinde geçerlidir).
3. Mahkeme kararı üretir. Karar bağlayıcıdır. Çorap yine tek kalır.

## Kuruluş

```bash
python3 lahey_corap.py
```

Python 3 yeter. Avukat gerekmez. Çamaşır sepeti tavsiye edilir.

## Kullanım

Program sorular sorar. Ciddi cevap verin. Şaka yapmayın. Şaka yapmak davayı düşürür.

## Sorumluluk reddi

Bu yazılım kayıp çorabı geri getirmez. Sadece onurunu iade eder. Onur iade edilince çorap yine tek kalır. Bu bir özelliktir.
